1. ภาพรวม

โค้ดนี้สร้าง ตารางแสดงข้อมูลเพื่อน 5 คน ที่มีรูปภาพและปุ่มลิงค์ Social Media แบ่งเป็น 2 ส่วนหลัก:

<head>

โหลด Font Awesome ผ่าน CDN เพื่อใช้ไอคอน Social Media ในหน้าเว็บ

<body>

โค้ด <table> ที่มีหัวตาราง, แถวข้อมูล, รูปภาพ และปุ่มลิงค์ Social

💡 Font Awesome คือ library ไอคอนฟรี — โหลดครั้งเดียวใน <head> แล้วใช้ได้ทุกที่ในหน้าเว็บผ่านแท็ก <i class="fa-brands fa-facebook">
2. <head> — โหลด Font Awesome
🔒 no copy
<head>
  <!-- base target ทำให้ลิงค์ทุกตัวเปิดแท็บใหม่ -->
  <base target="_top">

  <!-- โหลด Font Awesome จาก CDN -->
  <link rel="stylesheet"
       href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css">
</head>
แท็ก / Attributeหน้าที่
<base target="_top">กำหนดให้ลิงค์ทุกตัวในหน้าเปิดในแท็บหลัก (ใช้เมื่อรันใน iframe เช่น Google Sites)
<link rel="stylesheet">โหลดไฟล์ CSS จากภายนอก — ในที่นี้คือ Font Awesome icon library
href="https://cdnjs..."URL ของไฟล์ Font Awesome บน CDN (Content Delivery Network) ไม่ต้องดาวน์โหลดเก็บเอง
3. โครงสร้าง <table>
🔒 no copy
<table border="1" style="border-collapse: collapse;">

  <!-- ชื่อตาราง -->
  <caption>5 อันดับ เพื่อนของฉัน</caption>

  <!-- แถวหัวตาราง -->
  <tr>
    <th>ลำดับ</th>
    <th>ชื่อ - นามสกุล</th>
    ... (th อื่นๆ)
  </tr>

  <!-- แถวข้อมูล (ทำซ้ำสำหรับแต่ละคน) -->
  <tr>
    <td>1</td>
    <td>นายวุฒิกร คำแก้ว</td>
    ... (td อื่นๆ)
  </tr>

</table>
แท็ก / Attributeหน้าที่
<table border="1">สร้างตาราง — border="1" ทำให้มีเส้นขอบ
border-collapse: collapseรวมเส้นขอบของเซลล์ติดกันให้เป็นเส้นเดียว (ป้องกันเส้นซ้อน)
<caption>ชื่อ/หัวข้อของตาราง แสดงอยู่ด้านบน
<tr>Table Row — หนึ่งแถวในตาราง
<th>Table Header — หัวคอลัมน์ ข้อความจะเป็น ตัวหนา และอยู่กึ่งกลางโดยอัตโนมัติ
<td>Table Data — เซลล์ข้อมูลปกติ
4. คอลัมน์รูปภาพ — <img> ใน <td>
🔒 no copy
<td>
  <img src="https://drive.google.com/thumbnail?id=1qbIbz0Gx1ez...&sz=w1000"
       alt="google logo"
       style="width: 100px; height: auto">
</td>
Attributeค่าหมายความว่า
src="..."URL รูปภาพที่มาของรูป — ใช้ Google Drive thumbnail URL ได้
alt="..."ข้อความสำรองข้อความที่แสดงเมื่อรูปโหลดไม่ได้ และช่วย Accessibility
width: 100px100pxกำหนดความกว้างรูป 100 พิกเซล
height: autoautoความสูงปรับตามสัดส่วนอัตโนมัติ ไม่บิดเบี้ยว
💡 Google Drive Thumbnail URL: ใช้รูปแบบ https://drive.google.com/thumbnail?id=FILE_ID&sz=w1000 โดย FILE_ID คือ ID ที่อยู่ใน URL ของไฟล์รูปใน Google Drive
5. ไอคอน Social — Font Awesome
🔒 no copy
<td>
  <!-- ไอคอน Facebook พร้อมลิงค์ -->
  <a href="https://www.facebook.com/nuy.lodtongsri" target="_blank">
    <i class="fa-brands fa-facebook" style="font-size: 30px;"></i>
  </a>

  <!-- ไอคอน Instagram พร้อมลิงค์ -->
  <a href="https://www.instagram.com/" target="_blank">
    <i class="fa-brands fa-instagram" style="font-size: 30px;"></i>
  </a>
</td>
Class / Attributeหน้าที่
fa-brandsบอกว่าเป็นไอคอน แบรนด์/โลโก้ เช่น Facebook, YouTube (ต้องมีทุกครั้ง)
fa-facebookชื่อไอคอน — เปลี่ยนส่วนนี้เพื่อเลือกไอคอนอื่น
font-size: 30pxขนาดของไอคอน — ปรับตัวเลขได้ตามต้องการ
target="_blank"เปิดลิงค์ในแท็บใหม่

ตัวอย่างไอคอน Social ที่ใช้บ่อย:

fa-facebook
fa-instagram
fa-youtube
fa-x-twitter
fa-tiktok
fa-linkedin
🔍 ค้นหาชื่อไอคอนเพิ่มเติมได้ที่ fontawesome.com/icons — กรองด้วย "Brands" เพื่อดูเฉพาะไอคอนแบรนด์ทั้งหมด
6. ความแตกต่าง <th> กับ <td>
ลำดับ ชื่อ - นามสกุล ชื่อเล่น
1 นายวุฒิกร คำแก้ว บอย
2 นางสาววิชชุดา กันทะมาลา วิชชี่
แท็กลักษณะใช้ตอนไหน
<th>ตัวหนา + จัดกึ่งกลาง (โดย browser อัตโนมัติ)แถวหัวตาราง — บอกว่าคอลัมน์นั้นเก็บข้อมูลอะไร
<td>ข้อความปกติ + ชิดซ้ายข้อมูลทั่วไปในแต่ละแถว
7. ตัวอย่างผลลัพธ์ (Preview)
5 อันดับ เพื่อนของฉัน
ลำดับ ชื่อ - นามสกุล ชื่อเล่น อาหารที่ชอบ รูปเพื่อน Social
1 นายวุฒิกร คำแก้ว บอย ผัดไทย
2 นางสาววิชชุดา กันทะมาลา วิชชี่ ข้าวมันไก่ ...... ......
3 นางสาวนิตติญา ลอดทองสี นุ้ย แกงปลา ...... ......
💡 แถวที่ 2-5 ยังมี ...... อยู่ — นักเรียนต้องเพิ่มรูปและลิงค์ Social ให้ครบเองในแบบฝึกหัด
8. แบบฝึกหัด — เติมข้อมูลเพื่อนของตัวเอง

เติมช่องสีเหลืองในส่วน <body> — เปลี่ยนข้อมูลให้เป็นเพื่อนของตัวเอง 5 คน พร้อมรูปและลิงค์ Social

</head>
<body>

<table border="1" style="border-collapse: collapse;">
  <!-- เปลี่ยนชื่อตาราง -->
  <caption></caption>

  <tr>
    <th>ลำดับ</th><th>ชื่อ - นามสกุล</th><th>ชื่อเล่น</th>
    <th>อาหารที่ชอบ</th><th>รูปเพื่อน</th><th>Social</th>
  </tr>

  <!-- แถวที่ 1 -->
  <tr>
    <td>1</td>
    <td></td>
    <td></td>
    <td></td>
    <td><img src="" alt="" style="width:100px;height:auto"></td>
    <td>
      <a href="" target="_blank">
        <i class="fa-brands fa-facebook" style="font-size:30px;"></i>
      </a>
      <a href="" target="_blank">
        <i class="fa-brands fa-instagram" style="font-size:30px;"></i>
      </a>
    </td>
  </tr>

  <!-- ทำซ้ำแถว <tr> ... </tr> สำหรับเพื่อนคนที่ 2–5 -->

</table>
</body>
</html>
