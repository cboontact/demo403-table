โหลด Font Awesome + Google Font Sriracha + กำหนด font-family ให้ body

ตาราง 6 คอลัมน์ — ลำดับ, ชื่อ, ชื่อเล่น, อาหาร, รูปภาพ, ไอคอน Social

2. <head> — โหลด Google Font & Font Awesome
✅ copy ได้
<head>
  <base target="_top">

  <!-- Font Awesome สำหรับไอคอน Social -->
  <link rel="stylesheet"
       href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css">

  <!-- preconnect ช่วยให้โหลด Google Font เร็วขึ้น -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

  <!-- โหลด Sriracha font -->
  <link href="https://fonts.googleapis.com/css2?family=Sriracha&display=swap" rel="stylesheet">

  <!-- ใช้ฟอนต์กับทุก element ใน body -->
  <style>
    body {
      font-family: 'Sriracha', sans-serif;
    }
  </style>
</head>
แท็ก / Attributeหน้าที่
<link rel="preconnect">บอก browser ให้เชื่อมต่อกับ server Google Font ล่วงหน้า ทำให้โหลดฟอนต์เร็วขึ้น
crossoriginอนุญาตให้ดึงทรัพยากรข้าม domain (จำเป็นสำหรับ fonts.gstatic.com)
family=Srirachaชื่อฟอนต์ที่ต้องการจาก Google Fonts
display=swapแสดงข้อความด้วยฟอนต์สำรองก่อน แล้วค่อยสลับเป็น Sriracha เมื่อโหลดเสร็จ
font-family: 'Sriracha', sans-serifใช้ฟอนต์ Sriracha กับทุก element — ถ้าโหลดไม่ได้ให้ใช้ sans-serif แทน
สวัสดีครับ — Hello! 123 ABC ก ข ค
ตัวอย่างฟอนต์ Sriracha — ฟอนต์ไทย/อังกฤษสไตล์ลายมือ น่ารัก อ่านง่าย
💡 Google Fonts มีฟอนต์ไทยให้เลือกมากกว่า 30 แบบ — ค้นหาเพิ่มเติมได้ที่ fonts.google.com กรองด้วย "Thai"
3. โครงสร้าง <table>
✅ copy ได้
<table border="1" style="border-collapse: collapse;">

  <!-- ชื่อตาราง -->
  <caption>5 อันดับ เพื่อนของฉัน</caption>

  <!-- แถวหัวตาราง -->
  <tr>
    <th>ลำดับ</th>
    <th>ชื่อ - นามสกุล</th>
    <th>ชื่อเล่น</th>
    <th>อาหารที่ชอบ</th>
    <th>รูปเพื่อน</th>
    <th>Social</th>
  </tr>

  <!-- แถวข้อมูล (ซ้ำสำหรับแต่ละคน) -->
  <tr> ... </tr>

</table>
แท็ก / Attributeหน้าที่
<table border="1">สร้างตาราง — border="1" ทำให้มีเส้นขอบ
border-collapse: collapseรวมเส้นขอบของเซลล์ติดกันให้เป็นเส้นเดียว ไม่ซ้อนกัน
<caption>ชื่อตาราง แสดงอยู่ด้านบนโดยอัตโนมัติ
<tr>Table Row — หนึ่งแถว
<th>Table Header — หัวคอลัมน์ ตัวหนา+กึ่งกลางอัตโนมัติ
<td>Table Data — เซลล์ข้อมูลปกติ
4. คอลัมน์รูปภาพ — <img> ใน <td>
✅ copy ได้
<td>
  <img src="https://drive.google.com/thumbnail?id=1y8cJMvsWfi0xrLTyChn08BhtSDtZkfvB&sz=w1000"
       alt="wt"
       style="width: 100px; height: auto">
</td>
Attributeค่าหมายความว่า
src="..."Google Drive URLที่มาของรูป — ใช้ thumbnail URL จาก Google Drive ได้เลย
alt="wt"ข้อความสำรองแสดงเมื่อรูปโหลดไม่ได้ และช่วย Screen Reader
width: 100px100pxกำหนดความกว้างรูป
height: autoautoความสูงปรับตามสัดส่วนอัตโนมัติ ไม่บิดเบี้ยว
💡 Google Drive Thumbnail URL: รูปแบบ https://drive.google.com/thumbnail?id=FILE_ID&sz=w1000 — นำ ID จาก URL ของไฟล์รูปใน Drive มาแทน FILE_ID
5. ไอคอน Social — แต่ละแถวใช้ไอคอนต่างกัน

ในโค้ดนี้แต่ละคนมีไอคอน Social ต่างกัน — เปลี่ยนแค่ชื่อ class และ URL ลิงค์

✅ copy ได้
<!-- แถว 1: Facebook (fa-facebook-f = ตัว f เท่านั้น) -->
<a href="https://www.facebook.com/" target="_blank">
  <i class="fa-brands fa-facebook-f" style="font-size: 40px;"></i>
</a>

<!-- แถว 2: Instagram แบบมีกรอบสี่เหลี่ยม -->
<a href="https://www.instagram.com/" target="_blank">
  <i class="fa-brands fa-square-instagram" style="font-size: 40px;"></i>
</a>

<!-- แถว 3: YouTube -->
<a href="https://www.youtube.com/" target="_blank">
  <i class="fa-brands fa-youtube" style="font-size: 40px;"></i>
</a>

<!-- แถว 4: TikTok -->
<a href="https://www.tiktok.com/th-TH/" target="_blank">
  <i class="fa-brands fa-tiktok" style="font-size: 40px;"></i>
</a>

<!-- แถว 5: ยังไม่กำหนด URL -->
<a href="........................" target="_blank">
  <i class="fa-brands fa-facebook-f" style="font-size: 40px;"></i>
</a>
Class ไอคอนรูปแบบที่ได้ใช้ใน
fa-facebook-fตัวอักษร f เท่านั้น ไม่มีกรอบแถว 1, 5
fa-square-instagramโลโก้ Instagram ในกรอบสี่เหลี่ยมแถว 2
fa-youtubeโลโก้ YouTubeแถว 3
fa-tiktokโลโก้ TikTokแถว 4

ตัวอย่างไอคอนแต่ละแบบ:

fa-facebook-f
fa-facebook
fa-square-instagram
fa-instagram
fa-youtube
fa-tiktok
🔍 ค้นหาชื่อไอคอนเพิ่มเติมได้ที่ fontawesome.com/icons — กรองด้วย "Brands"
⚠️ แถว 5: href="........................" ยังไม่ได้ใส่ URL จริง — ต้องเปลี่ยนเป็นลิงค์จริงก่อนส่งงาน
6. ความแตกต่าง <th> กับ <td>
ลำดับ ชื่อ - นามสกุล ชื่อเล่น
1 นายวุฒิกร คำแก้ว บอย
2 นางสาววิชชุดา กันทะมาลา วิชชี่
แท็กลักษณะใช้ตอนไหน
<th>ตัวหนา + จัดกึ่งกลาง (browser ทำให้อัตโนมัติ)แถวหัวตาราง
<td>ข้อความปกติ + ชิดซ้ายข้อมูลทั่วไปทุกแถว
7. ตัวอย่างผลลัพธ์ (Preview)
5 อันดับ เพื่อนของฉัน
ลำดับ ชื่อ - นามสกุล ชื่อเล่น อาหารที่ชอบ รูปเพื่อน Social
1 นายวุฒิกร คำแก้ว บอย ผัดไทย
2 นางสาววิชชุดา กันทะมาลา วิชชี่ ข้าวมันไก่
3 นางสาวนิตติญา ลอดทองสี นุ้ย แกงปลา
4 นางเมธาวี ไชยแก้ว หล้า ผัดพริกแกง
5 นายทยากร ใจหวัน ต่อ ผัดคะน้า
💡 Preview ใช้ฟอนต์ Sriracha เหมือนโค้ดจริง — สังเกตว่าตัวอักษรมีสไตล์ต่างจากฟอนต์ปกติ
